# TravelSynth

![TravelSynth](public/og-image.png)

A high-fidelity, personalized travel itinerary generator built with React, TypeScript, and Vite, powered by the Google Gemini API. Structures comprehensive daily travel schedules, stay recommendations, and practical localized advice based on user budget, interests, origin, and transport modes.

## Features

- Comprehensive preference form — origin, destination, trip length, budget tiers, travel modes, multi-select interests, freeform text inputs
- Structured day-by-day timelines — Morning/Afternoon/Evening schedules with locations, estimated costs, durations, and category indicators
- Smart stays & tips — lodging recommendations matched to budget, plus cultural, packing, transit, and security tips
- LocalStorage travel history — tracks and preserves generated itineraries for comparison
- Secure local key configuration — browser-stored Gemini API key, never sent to external servers
- Dynamic theme system — glassmorphism look with dark and light themes
- Print & PDF layouts — optimized typography for printing or saving as PDF
- Interactive quick templates — fast-fill suggestions (Paris Explorer, Tokyo Culinary, Swiss Alps Road Trip)
